# Compatibility

Games tested in Zakuro so far, as of v0.2.23. Recompiled means the game was tested with its code recompiled by [3dsrecomp](https://github.com/fearkov/3dsrecomp), which is how it runs at full speed; without it, it runs in the interpreter, slower.

| Status | Meaning |
|---|---|
| Playable | Can be played, from the start through the game |
| In-game | Gets into the game, with issues |
| Intro | Gets to menus or the intro |
| Boots | Starts, but stops early |
| Nothing | Doesn't start |
